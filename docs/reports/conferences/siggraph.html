关键奖项与论文精读

  • Technical Papers Best Paper Award · GimmBO: Interactive Generative Image Model Merging via Bayesian Optimization

    把图像生成适配器的融合权重当成搜索变量。用户比较生成样张，偏好贝叶斯优化根据选择推荐下一组权重，减少反复拖动滑块的成本。关键是人的反馈如何引导参数搜索，并不是重训底模。

    获奖记录

  • Technical Papers Best Paper Award · Inverse Rendering for Discrete X-Ray Computed Tomography

    将每个体素表示为已知材料类别上的概率分布，再用实测投影与可微渲染预测的一致性作梯度反演。支持散射等非线性效应，在论文测试的稀疏投影和有限角度条件下尤其有优势；前提是材料类别已知。

    获奖记录

  • Technical Papers Best Paper Award · Walk on Decomposed Subdomains: A Hybrid Monte Carlo-Deterministic Solver for Elliptic PDEs

    把复杂域拆成可处理的子域，用蒙特卡洛估计局部求解算子，再以稀疏线性系统耦合子域边界。把随机采样留给易并行的局部步骤，把全局一致性交给确定性求解。

    获奖记录

研究方向

基于所列论文的观察，不代表全会趋势、占比或首创结论。

技术趋势

  • 用真实动态照明训练人像视频换光

    Pixel Cube 用高速采集系统重现照明变化，并将实拍与合成数据用于训练视频扩散模型。逐帧 HDR 环境图指定目标光照，人物运动时既可检验阴影和高光是否跟随光源，也可检查相邻帧的人脸细节是否稳定。

    支撑论文：Pixel Cube（作者论文）

新模型范式

  • 用三维框为二维图像编辑指定姿态

    BoxCtrl 把平移、旋转和缩放编码成彩色三维包围盒提示，将目标几何与物体原有外观分开表达。模型先接受监督微调，再以强化学习提高变换精度；可分别检查输出是否服从目标位置和旋转角度，以及物体是否仍保留原来的材质和结构。

    支撑论文：BoxCtrl（SIGGRAPH 技术论文）

新概念

  • 反演时，关键是选对未知量与观测

    两篇获奖工作是互补例子：GimmBO 的未知量是适配器融合系数，反馈是人的样张偏好；离散 CT 则从物理投影估计已知材质的体素分布。它们的求解器并不通用，但都说明先明确参数和反馈，比直接增加生成或采样预算更有针对性。此处为获奖案例对读，不是全会统计。

    支撑论文：GimmBO 作者项目 · 离散 CT 逆渲染作者论文

技术趋势

  • 把云端渲染的降噪和传输一起优化

    这项云渲染工作联合训练路径追踪的自适应采样、降噪与视频压缩，并利用客户端已有的几何缓冲信息重建画面。在固定带宽下比较画质时，服务器采样开销与客户端可用信息都应作为实验条件。

新模型范式

    TokenVerse 将图像说明中的词与模型调制方向关联。在多个来源间组合概念时，可以固定主体并替换姿势或光照，分别观察主体是否保留、属性是否跟随目标条件。

    支撑论文：TokenVerse: Versatile Multi-concept Personalization in Token Modulation Space

    支撑论文：CAST: Component-Aligned 3D Scene Reconstruction from an RGB Image

研究方向

基于所列论文的观察，不代表全会趋势、占比或首创结论。

技术趋势

  • 把大场景辐射场拆成可流式加载的局部模型

    SMERF 按空间层次划分辐射场，渲染时根据相机位置选择局部模型，从而限制单次访问的内存与计算量。局部模型通过蒸馏保持一致，评估移动端漫游时还可检查相机跨越分区后画面是否跳变。

    支撑论文：SMERF（ACM 论文）

新模型范式

  • 为生成的三维资产指定空间约束

    只用提示词很难精确表达物体占据哪一块空间。CLAY 让体素、包围盒、点云等输入直接控制生成过程，提供了比较语义描述、二维参考和三维结构约束的同一实验平台。

    支撑论文：CLAY: A Controllable Large-scale Generative Model for Creating High-quality 3D Assets

新概念

  • 用一张已调色的图改变其他视角

    拍同一场景时，相机会对不同视图分别调整颜色与曝光。Bilateral Guided Radiance Field Processing 在训练阶段先吸收这些视图差异，再把用户对单张图的修改传播到三维场景；评估时可沿相机轨迹检查调色是否稳定。

    支撑论文：Bilateral Guided Radiance Field Processing
