PS-Diffusion: Photorealistic Subject-Driven Image Editing with Disentangled Control and Attention

本文提出了一种端到端的 PS-Diffusion 方法，通过解耦控制信号和效果注意力模块，实现了具有真实感且保持主体身份一致的场景驱动图像编辑。

解决的问题

现有基于扩散模型的主体驱动图像编辑方法主要关注语义一致性，却忽视了物体与场景间的上下文交互（如反射、光照和阴影），导致难以获得真实感结果；此外，两阶段生成方法在移除和插入阶段存在上下文交互不一致的问题，且缺乏足够的配对数据。

主要贡献

  • 提出了 PS-Diffusion 方法，通过解耦控制信号确保上下文交互和主体身份的一致性，使模型能识别交互而不受掩膜限制。
  • 设计了效果注意力模块（EAM），在去噪 U-Net 中重组交互区域和光照条件的结构特征，从而分离交互学习与主体学习以提升视觉效果的可信度。
  • 构建了名为 Replace-5K 的合成数据集，包含 5,000 对图像，用于模拟场景与物体之间的交互。
  • 在合成和真实世界数据集上进行了大量实验，验证了该方法在保持主体一致性和生成真实感交互效果方面的有效性。

SynLF: Zero-Shot Metric Depth from Light Field Cameras via Physics-Grounded Synthesis

SynLF 通过结合物理基础的轻场合成与可见性感知深度估计网络，解决了现有基于学习的轻场深度估计因训练数据稀缺而导致的泛化能力差和几何推理不稳健的问题。

解决的问题

现有基于学习的轻场深度估计方法受限于训练数据稀缺，导致模型容易过拟合理想化的朗伯体外观，难以泛化到真实世界的复杂场景（如遮挡、非朗伯体表面和无纹理区域），且缺乏显式的可见性约束导致几何推理脆弱。

主要贡献

  • 提出了 PG-LF 合成，这是一种物理基础的轻场合成流程，能够从丰富的 RGB-D 数据中即时生成监督轻场，无需预渲染的轻场数据集。
  • 引入了 VisDepth，这是一种基于先验初始化且具备可见性感知的迭代估计器，能够显式地对多视角遮挡进行推理，从而实现稳健的轻场度量深度估计。
  • 构建了 SynLF 框架，该框架在具有挑战性（如透明、镜面反射和无纹理区域）的真实世界轻场采集数据上展现了强大的零样本泛化能力，无需微调即可实现准确的度量深度估计。
  • 通过耦合合成管道和迭代估计器，利用相同的深度感知投影算子，强制模型进行严格的几何推理而非过度拟合外观捷径，为真实世界条件下的轻场度量深度估计提供了可扩展且鲁棒的解决方案。

解决的问题

现有二值散焦技术虽然能大幅提升投影速度，但二值条纹对正弦波的近似必然引入高阶谐波误差，导致相位恢复精度下降，且传统方法难以有效校正这些残余相位误差。

主要贡献

  • 系统分析了误差扩散核在条纹二值化过程中的作用，实验结果表明相位误差与误差扩散方向之间存在强相关性。
  • 提出了一种适用于四步相移法的鲁棒二值化策略，通过对条纹图案应用不同方向的误差扩散核实现条纹间自补偿，相比现有优化方法将相位误差降低了约 23.77%。
  • 通过广泛的对比实验验证了所提策略在高速三维测量中的高精度和有效性。

NavWM: A Unified Navigation World Model for Foresight-Driven Planning

NavWM 是一个统一的导航世界模型，它通过共享的双向 Mamba 骨干架构联合学习结构化感知、可控世界建模和多模态动作预测，并利用基于锚点的多模态轨迹预测框架和潜在世界令牌来支持通过视觉前瞻进行闭环规划。

解决的问题

现有视觉导航方法存在三个关键挑战：首先，模块化管道通常将导航策略和世界模型分开训练，导致无法利用共享的时空动态；其次，尽管有尝试统一两者的工作，但其潜在表示缺乏明确的场景抽象，难以支持稳定的长视界预测；最后，现实导航具有内在的多模态未来特性，而许多现有方法将动作预测坍缩为单一轨迹，导致动作过于集中且容易陷入局部最优。

主要贡献

  • 提出了 NavWM，这是一个统一的导航世界模型，它在共享架构中联合学习结构化感知、可控世界建模和多模态动作预测。
  • 引入了一种基于世界模型的视觉前瞻规划机制，该机制通过模拟未来观察来评估候选轨迹，从而实现了目标对齐的闭环导航。
  • 设计了专用的潜在世界令牌以捕捉环境的几何和语义线索，并通过深度和语义信号进行监督，以提供物理基础的上下文并提高长视界预测的稳定性。
  • 采用了基于锚点的多模态轨迹预测框架，生成多样化且物理合理的运动假设，从而扩展候选动作空间并增强模型在复杂环境中的探索能力。
  • 在多个机器人数据集上进行了广泛的实验，证明 NavWM 在视觉状态模拟和复杂导航任务中均取得了卓越的性能，显著提升了图像生成质量和导航成功率。
  • 通过消融实验验证了推理、控制和世界建模的联合训练能够产生相互增强的效果，这主要归功于它们对底层时空动态的共同依赖。
