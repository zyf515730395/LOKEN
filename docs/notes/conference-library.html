PS-Diffusion: Photorealistic Subject-Driven Image Editing with Disentangled Control and Attention

本文提出了一种端到端的 PS-Diffusion 方法，通过解耦控制信号和效果注意力模块，实现了具有真实感且保持主体身份一致的场景驱动图像编辑。

解决的问题

现有基于扩散模型的主体驱动图像编辑方法主要关注语义一致性，却忽视了物体与场景间的上下文交互（如反射、光照和阴影），导致难以获得真实感结果；此外，两阶段生成方法在移除和插入阶段存在上下文交互不一致的问题，且缺乏足够的配对数据。

主要贡献

  • 提出了 PS-Diffusion 方法，通过解耦控制信号确保上下文交互和主体身份的一致性，使模型能识别交互而不受掩膜限制。
  • 设计了效果注意力模块（EAM），在去噪 U-Net 中重组交互区域和光照条件的结构特征，从而分离交互学习与主体学习以提升视觉效果的可信度。
  • 构建了名为 Replace-5K 的合成数据集，包含 5,000 对图像，用于模拟场景与物体之间的交互。
  • 在合成和真实世界数据集上进行了大量实验，验证了该方法在保持主体一致性和生成真实感交互效果方面的有效性。

SynLF: Zero-Shot Metric Depth from Light Field Cameras via Physics-Grounded Synthesis

SynLF 通过结合物理基础的轻场合成与可见性感知深度估计网络，解决了现有基于学习的轻场深度估计因训练数据稀缺而导致的泛化能力差和几何推理不稳健的问题。

解决的问题

现有基于学习的轻场深度估计方法受限于训练数据稀缺，导致模型容易过拟合理想化的朗伯体外观，难以泛化到真实世界的复杂场景（如遮挡、非朗伯体表面和无纹理区域），且缺乏显式的可见性约束导致几何推理脆弱。

主要贡献

  • 提出了 PG-LF 合成，这是一种物理基础的轻场合成流程，能够从丰富的 RGB-D 数据中即时生成监督轻场，无需预渲染的轻场数据集。
  • 引入了 VisDepth，这是一种基于先验初始化且具备可见性感知的迭代估计器，能够显式地对多视角遮挡进行推理，从而实现稳健的轻场度量深度估计。
  • 构建了 SynLF 框架，该框架在具有挑战性（如透明、镜面反射和无纹理区域）的真实世界轻场采集数据上展现了强大的零样本泛化能力，无需微调即可实现准确的度量深度估计。
  • 通过耦合合成管道和迭代估计器，利用相同的深度感知投影算子，强制模型进行严格的几何推理而非过度拟合外观捷径，为真实世界条件下的轻场度量深度估计提供了可扩展且鲁棒的解决方案。

TEASR: Training-Efficient Any-Step Diffusion Transformer for Real-World Image Super-Resolution

TEASR 是一种训练高效的任意步扩散 Transformer，通过自对抗蒸馏和双分支架构实现了无需额外教师模型即可在单步到多步之间灵活调整推理步数的实时图像超分辨率。

解决的问题

现有单步超分辨率方法在训练时需要维护多个教师模型或判别器，导致训练开销巨大且难以扩展到大规模架构，同时这些方法被限制在固定的采样范式下，无法根据实际需求调整推理步数以平衡效率与质量。

主要贡献

  • 提出 TEASR 框架，利用自对抗蒸馏技术消除训练过程中对辅助教师模型或判别器的需求，显著降低训练开销并支持大规模骨干网络的微调。
  • 引入时间感知校正机制，根据噪声水平自适应地调整校正强度，使恢复结果更精确地对齐真实数据分布。
  • 设计带有解耦时间步条件的双分支 DiT 架构，将生成先验与条件引导显式分离，确保在自一致目标中完整保留细粒度的噪声水平信息。
  • 证明该方法支持无缝的任意步采样，随着推理步数增加，恢复质量持续提升，并在多个数据集上优于最先进方法。

EvoTok: A Unified Image Tokenizer via Residual Latent Evolution for Visual Understanding and Generation

EvoTok 是一种统一的图像分词器，通过在共享潜在空间内利用残差演化过程将像素级特征演化为语义级特征，从而在实现任务解耦的同时保持跨任务的一致性。

解决的问题

现有统一视觉模型面临两大核心问题：一是纠缠式方法导致理解与生成任务在共享特征空间中产生优化冲突，二是解耦式方法因过度独立而破坏了特征间的内在一致性与相关性。

主要贡献

  • 提出 EvoTok，这是一种将图像表示为共享潜在空间内残差潜在演化轨迹的统一图像分词器。
  • 引入一种统一的训练目标，在任务解耦与跨任务一致性之间取得平衡，学习出同时适用于语义对齐和像素重建的视觉表示。
  • 通过大量实验证明，EvoTok 在视觉理解和生成基准测试上均取得了优越性能，且其有效性得到了全面验证。
  • 尽管仅使用 1300 万张图像进行训练，EvoTok 在 ImageNet-1K 上仍达到了具有竞争力的 rFID 分数，并在多项视觉理解任务中表现最佳。
  • 该方法通过级联残差向量量化分解图像，使早期阶段捕捉空间结构以支持高保真生成，同时使深层阶段逐步导向与预训练模型对齐的语义特征。

OmniFace: Bridging the Image-to-Video Gap for High-Fidelity Face Swapping via Diffusion Transformer

OmniFace 通过构建包含 SyncID-Pipe 数据管道、基于 Diffusion Transformer 的 OmniFace 框架以及 IDBench-V 基准测试，解决了视频换脸中身份相似性与属性保持不足的问题。

解决的问题

现有图像换脸方法直接应用于视频序列时，因缺乏对时间一致性的约束，会导致明显的闪烁和抖动伪影，且现有视频换脸模型在身份相似度和属性保持方面仍落后于图像换脸的最先进方法。

主要贡献

  • 提出了一种新的双向监督范式，利用 SyncID-Pipe 数据管道将图像换脸的优势有效迁移至视频领域。
  • 开发了基于 Diffusion Transformer 的 OmniFace 框架，通过模态感知条件机制、合成到真实训练策略及身份一致性奖励加权机制，实现了高保真且连贯的视频换脸。
  • 引入了 IDBench-V 综合基准测试，涵盖多种头部姿态、面部表情和光照条件的视频，并证明 OmniFace 在该基准上取得了最先进的性能。
  • 展示了所提框架的卓越通用性，能够无缝适应各种换脸相关任务。

Dense Dynamic Scene Reconstruction and Camera Pose Estimation from Multi-View Videos

本文研究了如何从多个自由移动摄像头的视频输入中恢复任意时间步的稠密动态场景并同时估计相机位姿。

解决的问题

现有动态场景重建方法仅限于单摄像头设置，无法处理多摄像头场景中的尺度模糊、有限重叠以及动态内容违反静态世界假设等关键挑战。

主要贡献

  • 提出了一种多摄像头跟踪框架，能够从多个自由移动摄像头实现一致的动态场景重建，据作者所知这是首个为此任务设计的工作。
  • 收集并公开了一个名为 MultiCamRobolab 的新数据集，以支持对多摄像头稠密动态场景重建方法的定量评估。
  • 展示了该方法在跟踪和重建结果上优于最先进方法，同时消耗更少的内存资源。
  • 引入了一种两阶段优化框架，第一阶段通过构建时空连接图扩展单摄像头 SLAM 至多摄像头，并利用前馈重建模型解决有限重叠下的初始化问题。
  • 在第二阶段利用稠密宽基线光流对应关系，通过优化稠密跨摄像头和单摄像头一致性来细化每帧的深度和相机位姿。

Modeling and Compensating Phase Error in High-speed 3D Reconstruction

本文针对高速三维重建中二值散焦技术引入的残余相位误差问题，提出了一种基于四步相移法的新型二值化策略，通过利用相邻条纹误差的相互补偿机制，在保持实时性的同时显著提高了相位测量精度。

解决的问题

现有二值散焦技术虽然能大幅提升投影速度，但二值条纹对正弦波的近似必然引入高阶谐波误差，导致相位恢复精度下降，且传统方法难以有效校正这些残余相位误差。

主要贡献

  • 理论上推导了基于误差扩散算法的二值化所引入相位误差的基本形式，揭示了该误差与相移步数、条纹周期及投影器散焦量无关的独特性质。
  • 系统分析了误差扩散核在条纹二值化过程中的作用，实验结果表明相位误差与误差扩散方向之间存在强相关性。
  • 提出了一种适用于四步相移法的鲁棒二值化策略，通过对条纹图案应用不同方向的误差扩散核实现条纹间自补偿，相比现有优化方法将相位误差降低了约 23.77%。
  • 通过广泛的对比实验验证了所提策略在高速三维测量中的高精度和有效性。
