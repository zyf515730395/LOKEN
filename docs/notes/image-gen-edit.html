[2609.01370] Diffusion Based Unpaired Data Learning for Inverse Problems

arXiv 原文

一句话结论

本文提出了一种名为 LUD-DIF 的方法，利用扩散模型从完全无配对的边际数据中解决逆问题，通过扩散对齐构建代理配对并推导可训练的双路径条件扩散目标，同时显式量化了弱耦合近似带来的偏差。

解决的问题

解决逆问题通常需要大量成对样本 {(x_i, y_i)} 进行监督训练，但在医疗或天文成像等实际场景中，获取成对数据成本极高或完全不可行，导致现有成对学习方法难以广泛应用。

创新点

  • 从变分推断的角度出发，在合理的数据先验假设下，将联合分布的证据下界（ELBO）进行解耦，为使用扩散模型解决无配对数据的逆问题提供了可行的训练算法。
  • 定量分析了假设引入的理论误差界限，并据此提出了一种基于定理启发式的超参数（S, V）选择策略，建立了具有理论依据且实用的模型调优方案。
  • 在自然图像去噪和超分辨率数据集上验证了所提方法，实验结果表明 LUD-DIF 在这些任务中均取得了卓越的性能。
  • 该方法仅依赖无配对的边际样本，并通过边际 - 条件分解构建了双路径条件扩散目标，无需依赖成对数据即可同时利用 p(x) 和 p(y) 的信息。
  • 该方法显式量化了由弱耦合近似引起的偏差，弥补了现有无配对学习框架在原理性推导和偏差量化方面的不足。

解决的问题

尽管视觉语言模型（VLMs）在生成科学图表方面取得了进展，但根据自然语言指令对现有图表进行精确修改的能力仍被严重忽视，且现有的图形编程语言（如 TikZ）因语法复杂和学习曲线陡峭而难以被人类和模型掌握。

创新点

  • 提出了一种可扩展的框架，能够从自然发生的科学图表集合中恢复合理的编辑对，解决了大规模高质量编辑监督数据稀缺的问题。
  • 发布了 DaEdiTikZ 数据集，包含 39.1 万个源自真实修订的 TikZ 编辑对（78.1 万个编辑实例），以及 DaEdiTikZ-Bench 基准，包含 790 个经人工完善的编辑实例。
  • 提出了一种结合微调（SFT）和基于奖励的优化（GDPO）的特定于编辑的后训练方法，联合学习图表重建和编辑，并使用互补奖励来优化渲染保真度和编辑应用。
  • 训练了两个紧凑型的 EdiTikZ 模型（4B 和 9B 参数），其中 9B 模型在人类评估中超越了 GPT-5.6-Sol 并媲美 Gemini-3.1-Pro，且具备向更复杂分布外（OOD）图表迁移的能力。

[2609.01607] Uncovering Understanding-Generation Synergy in Native Unified Multimodal Models: From Representation, Task to System

arXiv 原文

一句话结论

该研究在原生多模态设置下，从表示、任务和系统三个层面系统揭示了理解与生成能力之间的协同效应及其条件依赖性。

解决的问题

现有统一多模态模型（UMMs）虽然证明了理解与生成能力的共存，但缺乏关于两者联合学习如何相互影响（是相互促进还是产生干扰）的明确证据，且现有架构往往导致目标冲突或能力退化。

创新点

  • 提出了一种原生多模态设置（像素输入、像素输出），通过控制路由和参数共享策略，在表示、任务和系统三个层面隔离并研究了理解与生成之间的相互作用。
  • 揭示了理解与生成之间存在双向有益信号，但联合训练的效果取决于架构设计：密集共享模型会导致目标竞争，而任务解耦的 MoT 架构能实现两者的软对齐与共存。
  • 通过几何推理、矢量图形和 3D 空间智能等案例研究证明，当理解与生成任务依赖共享领域知识或能力时，联合训练能产生显著的任务级协同效应。
  • 在系统层面证实，对于需要紧密交互的复杂任务（如推理密集型图像编辑），端到端的统一多模态模型在性能上优于由独立理解和生成模型组成的代理管道。
  • 总结指出统一理解与生成的益处是条件性的，并据此提出了构建 UMMs 的具体指导原则：当学习目标冲突时应专门化计算，当知识与决策共享时应统一训练与推理。

[2609.01746] CAT-Flow: Curvature-Adaptive sTeps for Flow Matching

arXiv 原文

一句话结论

本文提出了一种将流匹配（Flow Matching）重构为梯度流的理论框架，并据此设计了两种无需额外训练且计算高效的自适应步长求解器 CAT-OT 和 CAT-OV，通过利用向量场的曲率信息来优化生成过程中的步长选择。

解决的问题

流匹配（Flow Matching）生成的样本质量高度依赖于积分区间的离散化方式，即步长的选择，而现有方法存在以下局限：固定均匀步长忽略了轨迹在不同时间步的难易程度变化；启发式动态调整或基于神经网络的步长调度方法要么缺乏对轨迹几何形状的考量，要么需要额外的训练开销或导致过拟合；传统的自适应 ODE 求解器虽然能调整步长，但在每一步需要多次神经网络函数评估，对于大规模模型而言计算成本过高；步长跳过方法仅能从预定义的离散集合中选择步长，适应性有限。

创新点

  • 建立了流匹配（在直流假设下）与梯度流之间的形式化联系，证明了在相同初始条件下两者具有相同的解，从而为借用优化领域的自适应步长直觉提供了理论依据。
  • 提出了两种自适应步长方法：基于时间曲率的 CAT-OT 和基于历史值曲率的 CAT-OV，它们分别通过向量场的时间导数有限差分近似和方差来估计曲率。
  • 设计了高效的实现方案，利用生成过程中已有的向量场信息来调整步长，无需额外的神经网络函数评估或训练过程，同时保证了截断误差为常数阶。
  • 在图像生成任务中验证了方法的有效性，证明在达到与基线方法相同图像质量分数的情况下，所需步数（或 NFEs）显著减少，且几乎不增加墙钟时间和额外 FLOPs。
  • 展示了在相同步数下，所提方法能获得比基线方法更高的图像质量分数，特别是在步数较少时性能提升更为明显。
  • 在多样化的真实用户提示（DiffDB）和三种互补的质量指标（提示对齐、美学质量、人类偏好）上进行了广泛实验，证实了该方法在效率和生成质量上的优越性。

[2609.02748] Balancing Frequencies and Pixels in Flow Matching

arXiv 原文

一句话结论

本文提出了一种名为 Focal Log-Frequency Loss (f\bm{f}-loss) 的频率域目标函数，通过平衡频谱中的训练信号来纠正自然图像功率谱与像素空间训练目标之间的不匹配，从而在无需修改模型架构的情况下显著提升流匹配模型的收敛速度和生成质量。

解决的问题

自然图像的功率谱遵循 1/f^2 分布，导致信号能量主要集中在低频部分，而感知上至关重要的细节（高频）能量稀疏；现有的像素空间训练目标受此主导，优化过程偏向低频残差，导致模型难以在训练早期捕捉到高频的结构模式和精细纹理。

创新点

  • 识别了自然图像的频谱结构与像素空间训练目标之间的根本性不匹配，证明了标准损失函数会偏向低频分量，尽管高频细节在感知质量中至关重要。
  • 提出了一种频谱平衡的目标函数，即 Focal Log-Frequency Loss (f\bm{f}-loss)，通过对数压缩的频谱误差应用焦点加权，使模型能够同时学习全局结构和细粒度模式。
  • 展示了一种简单的两阶段训练策略，先使用 f\bm{f}-loss 学习频谱结构，再使用标准像素损失 v\bm{v}-loss 细化空间一致性，显著加速了收敛并提升了生成质量。
  • 证明了该方法作为标准流匹配目标的即插即用替代方案，无需任何架构修改，即可在定量（FID）和定性指标上实现最先进的性能。
