[2609.01433] Gaussian Core LoRA: Distribution-Aware Dynamic Adaptation for Broad Concept Erasure

arXiv 原文

一句话结论

Gaussian Core LoRA 提出了一种分布感知的动态低秩适应方法，通过高斯支持门、高斯混合模型责任分配和动态核心机制，在共享 LoRA 空间中根据提示词在特征分布中的位置动态重构秩空间，以解决传统静态 LoRA 在宽泛概念擦除中存在的模式平均、覆盖不全及语义干扰问题。

解决的问题

现有基于 LoRA 的概念擦除方法多采用概念级静态建模，即针对人工定义的目标概念学习固定的低秩更新并应用于所有相关提示，这种方法忽略了扩散模型在特征空间中代表同一宽泛概念时的内部多样性（如不同身份实例、视觉模式或语义子类别占据不同区域），导致固定更新无法覆盖所有模式（模式平均）、难以处理困难模式或干扰邻近的良性语义。

创新点

  • 从特征分布视角重新定义概念擦除问题，论证了多模态概念分布使得静态 LoRA 容易陷入模式平均、模式覆盖不全以及语义干扰的困境。
  • 提出了 Gaussian Core LoRA，这是一种包含高斯支持门（用于粗粒度激活筛选）、高斯混合模型后验责任（用于软性潜在模式路由）和动态核心（用于提示条件化的秩空间重构）的动态低秩适应框架。
  • 验证了该方法能够利用单个共享适配器覆盖每个宽泛目标概念内的异构模式，而无需为特定模式进行单独的模型训练。
  • 证明了该设计可扩展至联合擦除多达 50 个身份/风格，并在对抗性提示和跨架构评估（SDXL 和 FLUX）下保持了良好的擦除与保留权衡。

  • 推出 CamEditor-Bench 评估套件，包含 462 个严格隔离的测试实例，并首创基于透视场（Perspective Fields）的无优化几何评估协议，以实现对绝对几何精度的显式评估。
  • 通过自动和人工评估证明，CameraEditor 在几何对齐和内容保持方面达到最先进水平，其性能提升源于显式的几何条件和顺序视觉参考，而非仅依赖骨干网络能力。

  • 利用预训练可观测性分析来识别可用的测量值，采用自然变异缩放来平衡优化过程，并使用解码校准将生成的控制表达为可比较的效果单位。
  • 在 SDXL 和 FLUX.1-dev 模型上评估了学习到的控制，涵盖了解码效应、漂移、排序、一致性和零样本组合等多个维度。
  • 实验表明 Measured Sliders 在光照方向上达到了 0.995 的相关系数，单调扫掠率达到 98.9%，且在选择性上比最强外部滑块高出 3.3 倍。
  • 预训练可观测性能够预测所有六个评估的学习结果，而解码校准将端点离散度从 63.2 倍降低至 2.2 倍。
