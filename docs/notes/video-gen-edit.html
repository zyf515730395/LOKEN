[2609.00610] Streaming4D: Accelerate 4D World Models via Block-wise Video Generation and Incremental Reconstruction

arXiv 原文

一句话结论

Streaming4D 提出了一种同步流式管道，通过将块级自回归视频生成与增量 3D 重建紧密集成，实现了低延迟的 4D 重建。

解决的问题

现有 4D 系统大多遵循离线解耦工作流（先生成完整视频序列，后重建几何），这种顺序依赖引入了 prohibitive latency，阻碍了真正的交互式 4D 合成。

创新点

  • 提出了紧密耦合的同步架构，统一了自回归视频生成与增量 4D 重建。
  • 设计了块级管道执行策略，通过重叠生成与重建过程来降低端到端延迟。
  • 证明了所提出的设计在保持几何质量和多视图一致性的同时，持续提高了运行时效率。
  • 在单张 RTX 4090 上实现了 1.21 倍至 1.24 倍的速度提升，同时保持了高保真的 4D 几何质量。

[2609.02367] The Missing Temporal Link: Temporal Context Routing for Script-Driven Audio-Video Generation

arXiv 原文

一句话结论

本文提出 Temporal Context Routing (TCR) 方法，通过扩展时间对齐至结构化脚本，解决了脚本驱动音视频生成中模态间同步但偏离脚本时间线的问题。

解决的问题

现有联合音视频生成器虽然实现了模态间的时间对齐，但仅将脚本指定的镜头和对话时间编码在文本中，未显式关联到模态的时间位置，导致生成内容虽模态同步但偏离脚本时间线。

创新点

  • 识别出脚本驱动生成中的时间差距：视频和音频可能保持相互同步，但无法遵循脚本时间线。
  • 提出关键见解，将时间对齐扩展到结构化脚本，使每个提示的指定时间成为两种模态的显式控制信号。
  • 引入 Temporal Context Routing (TCR)，将脚本时间映射到共享的音视频时间轴上，并独立路由每个提示的引导。
  • 开发了一种粗到细的数据构建管道，利用 Gemini 进行语义标注和粗略时间，并在 0.1 秒网格上细化镜头和对话时间。
  • 在 200 个测试脚本上评估了 TCR，相比最强开源基线显著降低了镜头边界误差并提高了对话时间准确性，且保持了视觉质量和音视频同步。
  • 用户研究表明 TCR 在所有五个评估维度上均优于现有方法。

[2609.06712] RoLA: Rotary-Positioned Low-Rank Linear Attention for Efficient Diffusion Transformers

arXiv 原文

一句话结论

RoLA 通过在后非线性低秩特征上应用旋转位置编码（RoPE）并复用预训练的低秩旋转调度，解决了视频扩散 Transformer 中相对位置几何与可复用线性全局摘要之间的结构性兼容问题。

解决的问题

在 3D-RoPE 视频扩散 Transformer 中，传统的线性注意力机制要求全局分支为查询无关的可复用摘要，而 RoPE 通过位置依赖的旋转编码相对几何，两者在通常的非线性线性注意力公式下存在冲突（即 RoPE 困境），导致旋转与非线性不交换，使得全局摘要与绝对位置纠缠。

创新点

  • 揭示了 3D-RoPE 视频 DiT 中的结构性兼容问题：即真正的低秩全局分支必须同时保持相对位置几何结构并作为查询无关的可复用线性摘要，而这两者在常规非线性线性注意力公式下是相互冲突的。
  • 提出了一种兼容的旋转低秩分支，该方法在非线性低秩特征图之后应用 RoPE，并复用预训练旋转调度中截断的子集，从而在交互层面保留相对位置结构的同时，保持了线性时间复杂度的可复用全局摘要，且无需引入新的位置参数。
  • 提供了机制层面的验证和实证分析，通过在主流开源视频模型的真实特征上进行机制实验，验证了该分支的相对位置行为，并在代表性骨干网络上通过生成实验展示了在高稀疏度和全栈推理下的有利质量 - 效率权衡。
