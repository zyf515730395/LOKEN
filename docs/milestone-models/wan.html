查看代际精读
版本
Wan 2.1精读
  • Wan2.1 T2V-1.3B：较小的文生视频模型，面向更低计算成本。
  • Wan2.1 T2V-14B：较大的文生视频模型，覆盖更高质量与分辨率。
  • Wan2.1 I2V-14B 480P / 720P：以输入图像为条件的两个分辨率档。
Wan2.1 First-Last-Frame-to-Video精读
  • Wan2.1 FLF2V-14B：14B 首尾帧控制模型，官方提供 720P 权重与推理代码。
Wan 2.2精读
  • Wan2.2 T2V-A14B：文生视频 MoE，总参数 27B、每阶段激活约 14B。
  • Wan2.2 I2V-A14B：图生视频 MoE，同样按去噪阶段选择专家。
  • Wan2.2 TI2V-5B：5B 稠密模型统一文生与图生视频，使用更高压缩率 VAE，支持 720P。
Wan2.2 S2V精读
  • Wan2.2 S2V-14B：以语音等音频信号驱动角色视频的官方模型。
Wan-Animate精读
  • Wan2.2 Animate-14B：统一角色动画与角色替换，利用参考视频的动作和表情驱动目标角色。
Wan-Animate-2精读
  • Wan-Animate-2 Base：官方于 8 月 7 日发布基础权重及推理脚本。
  • Wan-Animate-2 Distillation：同日发布的蒸馏权重；官方推理示例使用 10 步且不启用 CFG。
Wan 2.5 Preview · API 上线精读
  • Wan2.5 T2V Preview：北京 API 在 9 月 19 日上线，国际区 9 月 23 日；支持原生音视频生成。
  • Wan2.5 I2V Preview：同代图生视频服务，输入图像与提示共同约束有声视频。
Wan 2.6 · API 上线精读
  • Wan2.6 T2V：官方 API 表记录 12 月 3 日上线，支持多镜头叙事与更长有声片段。
  • Wan2.6 I2V：图生视频版本，强化声音、镜头安排和多人物对话。
Wan 2.6 Reference-to-Video精读
  • Wan2.6 R2V：使用参考视频保持角色外观和声音，支持多角色共同演出。
Wan 2.7 · API 上线精读
  • Wan2.7 T2V / I2V：文生和图生视频服务更新；后续 4 月 25 日及 6 月 12 日快照不能替代该代 API 上线日。
  • Wan2.7 R2V / Video Edit：同代参考生视频与视频编辑服务，扩展参考控制与修改能力。
Wan 3.0 · API 上线精读
  • Wan3.0 Video：统一参考、编辑、复刻与驱动，支持文本、图像、音频、视频四模态参考及最长 30 秒生成。
Wan 3.0 Prime · API 上线精读
  • Wan3.0 Video Prime：3.0 的速度档，保留四模态参考与最长 30 秒生成；具体架构和训练差异：/。
Wan2.1 VACE精读
  • Wan2.1 VACE-1.3B：480P 小型视频创建与编辑模型。
  • Wan2.1 VACE-14B：支持 480P / 720P 的较大模型，使用同一条件接口完成不同任务。
训练数据

大规模图像与视频经过质量、运动、文字和语义筛选及重描述；分阶段先学习图像，再联合视频训练。

官方说明扩大训练数据并引入更系统的美学标注，包括光照、构图、色彩等属性。

VAE 结构

因果 3D Wan-VAE 在时间维压缩 4 倍、空间维压缩 8 倍，可按块编码和解码视频。

TI2V-5B 的 Wan2.2-VAE 时间压缩 4 倍、空间压缩 16 倍；不能把这一配置套用到所有 A14B 模型。

生成主体网络

视频 DiT 使用完整时空注意力和文本交叉注意力，在视频潜变量上训练流匹配；模型提供 1.3B 与 14B 档。

A14B 使用高噪声与低噪声两个 DiT 专家；TI2V-5B 则为稠密模型。

训练 Trick
  • 图像预训练后联合图像与视频，并逐步增加分辨率与时长。
  • 高质量 SFT、数据清洗与视频描述改善运动和语义。
  • 按扩散时间步切换高噪声与低噪声专家。
  • 通过美学数据和较大训练集改善镜头、动作与视觉表现。

新提出的创新点
  • 因果视频 VAE 与时空 Transformer 组成可扩展的视频生成主线。
  • 噪声阶段 MoE 将布局建构与细节复原分配给不同专家。
  • 高压缩潜空间使较小模型支持统一文生和图生视频。
  • 公开能力变化（实现未披露）：统一角色动画与替换任务，以动作和表情驱动目标角色。
  • 公开能力变化（实现未披露）：将声音与视频作为同一次生成结果。
  • 公开能力变化（实现未披露）：统一多种视频创作操作，并支持四模态参考。
  • Video Condition Unit 将参考、编辑和掩码统一成输入接口。
  • Context Adapter 支持多任务组合，复用视频生成主干。
局限性
  • 论文明确指出大幅运动中的精细细节仍可能丢失；14B 模型推理计算开销较高。
