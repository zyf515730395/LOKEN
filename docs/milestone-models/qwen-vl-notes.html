QwenVL · Qwen-VL

文章精读

版本

Qwen-VL；发布节点 2023-08-24；变体：Qwen-VL、Qwen-VL-Chat。资料

训练数据

清洗后 1.4B 图文对；英文 77.3%、中文 22.7%。 官方资料.

VAE 结构

不适用：视觉理解与自回归文本输出，不使用图像生成 VAE。 官方资料.

Text Encoder

无独立条件文本编码器；文本进入语言模型词嵌入及解码器。 官方资料.

生成主体网络

Qwen-7B 中间检查点 + ViT 视觉编码器 + 跨模态适配器。 官方资料.

训练 Trick

先冻结 LLM 进行图文预训练，再联合多任务训练与 SFT；分辨率从224升至448。 官方资料.

新提出的创新点

将图文对话、文字识别和带位置的 grounding 统一到语言模型。 官方资料.

局限性

该版本尚未覆盖语音、视频及图像生成，论文将这些列为后续工作。 官方资料.
