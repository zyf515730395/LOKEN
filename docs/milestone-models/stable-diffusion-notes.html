[2112.10752] Stable Diffusion · Stable Diffusion 1.x

日期口径：1.x 官方公开发布日；1.5 只作代内变体，不虚构其精确日期。

一句话结论

把扩散过程移入压缩潜空间，使高质量文生图能在更有限的算力上运行。

解决的问题

直接在像素空间反复去噪开销高，需要保留图像细节而显著缩小扩散状态。

创新点

  • 将感知压缩与语义生成分开，减少高分辨率扩散的计算负担。

文章精读

版本

  • Stable Diffusion 1.4：2022 年 8 月公开发布的 1.x 主线权重，采用 512 级图像训练。
  • Stable Diffusion 1.5：官方后续 1.x 检查点，由 1.2 继续训练；此处作为同代变体比较，不把 8 月 22 日当作 1.5 的发布日期。

训练数据

使用 LAION 图文数据及其高分辨率、美学筛选子集，逐阶段提高训练分辨率和图像质量。

VAE 结构

自编码器把 RGB 图像压缩为空间缩小 8 倍、4 通道的潜表示；扩散完成后解码回图像。

Text Encoder

冻结的 CLIP ViT-L/14 文本编码器，通过交叉注意力给去噪网络提供条件。

生成主体网络

潜空间 U-Net，卷积层处理局部结构，注意力与交叉注意力连接全局及文本条件。

训练 Trick

  • 阶段性训练和文本条件随机丢弃支持 classifier-free guidance。

新提出的创新点

  • 将感知压缩与语义生成分开，减少高分辨率扩散的计算负担。

局限性

  • 无法稳定绘制可读文字，复杂的物体组合与空间关系容易出错，人物及面部也可能生成不正确。
  • 主要用英文描述训练，非英语提示的效果较弱；图像自编码器为有损压缩。官方模型卡

[2307.01952] Stable Diffusion · SDXL 1.0

一句话结论

扩展 U-Net、文本条件与分辨率条件，使潜空间扩散更适合高分辨率和多种宽高比。

解决的问题

放大旧模型容易暴露裁切和比例偏差，需要让训练时的图像尺寸、裁切位置进入条件。

创新点

  • 把数据预处理中的尺寸和裁切信息显式作为生成条件。
  • Base 与 Refiner 分工，且基础模型不依赖 Refiner 才能出图。

文章精读

版本

  • SDXL 1.0 Base：1024 级基础生成模型，可独立完成生成。
  • SDXL 1.0 Refiner：可选的低噪声精修模型，接续 Base 潜变量细化图像。

训练数据

高质量图文数据按多分辨率、多宽高比训练，并区分基础模型与精修阶段。

VAE 结构

沿用潜空间自编码器路线，改进训练以提高重建质量。

Text Encoder

CLIP ViT-L 与 OpenCLIP ViT-bigG 双编码器；序列特征与 pooled 文本特征共同提供条件。

生成主体网络

显著增大的 U-Net；Base 负责主要生成，可选 Refiner 在低噪声阶段细化局部。

训练 Trick

  • 原始尺寸、裁切坐标和目标尺寸的 micro-conditioning 减少训练裁切偏差。
  • 多宽高比训练与分阶段精修改善高分辨率输出。

新提出的创新点

  • 把数据预处理中的尺寸和裁切信息显式作为生成条件。
  • Base 与 Refiner 分工，且基础模型不依赖 Refiner 才能出图。

局限性

  • 仍不能可靠绘制可读文字，复杂物体组合和空间关系具有困难；人物与面部可能失真。
  • 尚未达到完全照片级真实感，自编码器仍会造成信息损失。官方模型卡

[2311.17042] Stable Diffusion · SDXL Turbo / SD-Turbo

一句话结论

用对抗式扩散蒸馏把多步生成压到极少步骤，同时保留教师模型的视觉先验。

解决的问题

多步扩散的交互延迟较高，单纯减少采样步数会损失质量。

创新点

  • 将扩散蒸馏的语义先验与对抗训练的锐利细节结合。

文章精读

版本

  • SDXL Turbo：由 SDXL 蒸馏的 ADD 模型，面向 1–4 步快速生成。
  • SD-Turbo：同一官方加速路线下由 SD 2.1 蒸馏的较小模型，并非 SDXL 检查点。 此节点日对应 SDXL Turbo 公告，不据此推定 SD-Turbo 的精确发布日。

训练数据

/

VAE 结构

/

Text Encoder

/

生成主体网络

学生沿用对应教师的潜空间扩散结构；SDXL Turbo 与 SD-Turbo 分别来自不同教师。

训练 Trick

  • ADD 联合扩散教师监督与对抗损失，使学生在少步采样下仍产生清晰图像。

新提出的创新点

  • 将扩散蒸馏的语义先验与对抗训练的锐利细节结合。

局限性

  • SDXL Turbo 与 SD-Turbo 均不能可靠绘制可读文字，人物及面部可能失真，自编码器仍为有损压缩；官方以 512×512 为首选生成尺度。SDXL Turbo 模型卡

[2403.03206] Stable Diffusion · Stable Diffusion 3 · API 上线

日期口径：官方 API 开放日；另明确记录预告日。

一句话结论

从 U-Net 转向多模态 Diffusion Transformer，用 rectified flow 统一学习图像与文本的生成关系。

解决的问题

复杂指令与文字绘制需要更充分的跨模态交互，也需要能随规模扩展的主干。

创新点

  • 扩展 MMDiT 和流匹配，使架构更适合统一图文与规模扩展。

文章精读

版本

  • Stable Diffusion 3：官方 API 基础版本；2 月 22 日为预告，4 月 17 日为 API 开放。
  • Stable Diffusion 3 Turbo：同日开放的速度档，具体独立训练和结构差异：/。

训练数据

大规模图文数据经过过滤与重新描述；论文研究数据、模型规模和采样目标对高分辨率合成的影响。

VAE 结构

空间压缩 8 倍、16 通道的图像潜变量，增加每个潜空间位置的信息容量。

Text Encoder

CLIP-L、OpenCLIP-G 与 T5-XXL 三路文本编码。

生成主体网络

MMDiT 为文本和图像保留独立参数，再进行联合注意力；采用 rectified flow 建模噪声到图像的运输。

训练 Trick

  • 研究时间步分布重加权以集中学习较有效的噪声阶段。
  • 图文各自变换与联合注意力兼顾模态特性和交互。

新提出的创新点

  • 扩展 MMDiT 和流匹配，使架构更适合统一图文与规模扩展。
