[2503.11651] VGGT · VGGT

日期口径：原始论文首次提交日；Commercial 增发日期在变体中单列。

一句话结论

用单次前馈网络联合恢复多视图几何，将传统重建流程中的多种估计任务共享建模。

解决的问题

相机、深度和对应关系互相依赖，独立估计再优化会增加复杂度和计算成本。

创新点

  • 帧内与跨帧注意力交替，让局部图像特征直接交换多视图几何信息。
  • 多任务监督共享主干，避免将几何估计拆成独立模型。

[2605.15195] VGGT · VGGT-Ω

一句话结论

减少几何重建训练的显存开销，用更大规模的真实与动态视频数据扩展空间理解。

解决的问题

全局注意力和高分辨率预测头占用大量显存，限制模型和数据规模。

创新点

  • 寄存器聚合跨视图信息，部分替代昂贵的全局 token 交互。
  • 用紧凑的相机和深度目标表达重建，减少预测头显存。

文章精读

版本

  • VGGT-Ω 1B：报告中的基础规模，使用寄存器注意力、精简预测头和扩大训练数据。
  • VGGT-Ω 10B：报告中的扩大规模模型；作为论文官方模型比较，不将论文评测等同于已开放全部权重。

训练数据

约 300 万有监督序列覆盖公开及内部静态、动态数据；另收集约 4000 万网络风格视频，筛选后用于自监督及几何伪标注。

生成主体网络

以 DINOv3 初始化，图像 patch 为 16；默认将 25% 全局注意力替换为仅寄存器间的注意力，使用轻量 MLP 与 pixel shuffle 预测头，直接输出相机和深度。

训练 Trick

  • 保留点图与匹配监督，但去掉其独立预测输出，减少冗余。
  • 监督训练结合未标注视频的自监督和动态场景标注流水线。

新提出的创新点

  • 寄存器聚合跨视图信息，部分替代昂贵的全局 token 交互。
  • 用紧凑的相机和深度目标表达重建，减少预测头显存。

局限性

  • 论文消融显示，把全部全局注意力替换为寄存器注意力虽更快，却会降低重建精度；默认只替换部分层。
