[2408.01XXX] FLUX · FLUX.1

一句话结论

FLUX.1 是由 Black Forest Labs 发布的基于 12B 参数的文本到图像生成模型套件，采用混合多模态与并行扩散 Transformer 架构及 Flow Matching 方法，包含 [pro]、[dev] 和 [schnell] 三个变体。

解决的问题

现有扩散模型在图像细节、提示词遵循、风格多样性和场景复杂性方面存在不足，同时需要提升硬件效率和生成速度，FLUX.1 旨在定义图像合成领域的新的最先进标准。

创新点

  • 基于 Flow Matching 的生成方法，包含扩散作为特例
  • 混合多模态与并行扩散 Transformer 块架构
  • 引入旋转位置嵌入和并行注意力层
  • 针对输出多样性的微调策略
  • 指导蒸馏技术用于 [dev] 变体
  • 支持多种分辨率和纵横比生成

文章精读

版本

  • FLUX.1 [pro]：提供最佳性能图像生成，通过 API 访问，支持企业定制解决方案
  • FLUX.1 [dev]：开放权重的指导蒸馏模型，适用于非商业应用，比同尺寸标准模型更高效
  • FLUX.1 [schnell]：专为本地开发和个人使用设计的最快模型，采用 Apache2.0 许可

  • 在高分辨率模式下维持了仅 10 秒的样本生成时间，性能优于同类高分辨率模型。
  • 新增 Raw Mode 模式，通过调整生成美学以捕捉 candid photography 的真实感，减少合成感并提升自然摄影的多样性。

[2411.21XXX] FLUX · FLUX.1 Tools

一句话结论

FLUX.1 Tools 是 Black Forest Labs 于 2024 年 11 月 1 日发布的 FLUX.1 架构大代际下的工具模型套件，旨在通过 FLUX.1 Fill、FLUX.1 Depth、FLUX.1 Canny 和 FLUX.1 Redux 四个变体为基于文本的图像生成提供结构引导、局部重绘及图像变体控制能力，同时明确宣布 FLUX.1 Depth 和 FLUX.1 Canny 已废弃。

解决的问题

基础文本到图像模型（FLUX.1）缺乏对图像局部区域的精确编辑能力、基于深度或边缘的结构化控制手段，以及在不改变原图风格下的图像变体生成能力，导致用户在修改现有图像或进行复杂重绘时难以保持结构一致性和语义连贯性。

创新点

  • FLUX.1 Fill 实现了超越现有工具（如 Ideogram 2.0）的先进局部重绘（inpainting）和扩展（outpainting）能力，支持基于文本描述和二进制掩码的无缝编辑。
  • FLUX.1 Redux 作为适配器，允许用户通过输入图像和文本提示混合并重新创建图像，实现了高质量的图像变体和风格迁移。
  • FLUX.1 Depth 和 FLUX.1 Canny 提供了基于深度图或 Canny 边缘的结构化引导，使用户能在保持原始图像核心构图的同时进行文本导向的编辑。
  • 所有工具模型均提供 [pro] 和 [dev] 两个版本，其中 [dev] 版本采用指导蒸馏（guidance-distilled）技术，在保持性能的同时提高了推理效率。
  • 建立了完整的开源生态支持，包括 Hugging Face 上的全量权重、LoRA 适配器以及 GitHub 上的推理代码，并支持通过合作伙伴平台访问。

文章精读

版本

  • FLUX.1 Fill：专注于图像局部重绘和扩展，支持基于文本和掩码的编辑，且未受废弃影响。
  • FLUX.1 Depth：提供基于深度图的结构引导以维持构图，但已被官方宣布废弃并停止维护。
  • FLUX.1 Canny：提供基于 Canny 边缘的结构引导以维持构图，但已被官方宣布废弃并停止维护。
  • FLUX.1 Redux：作为适配器实现图像变体和重风格化，支持结合图像与文本提示生成，未受废弃影响。

[2506.15742] FLUX · FLUX.1 Kontext

一句话结论

FLUX.1 Kontext 是 Black Forest Labs 发布的一套统一架构的生成式流匹配模型，通过简单的序列拼接方法将文本和图像输入结合，实现了局部编辑、全局编辑、角色/风格参考及文本编辑等任务，显著提升了多轮迭代工作流中的对象与角色一致性，并引入了 KontextBench 基准进行验证。

解决的问题

现有编辑模型在多轮迭代中常出现角色一致性和稳定性下降的问题，且传统图像处理管道缺乏对语义上下文的深层理解，难以在保持细粒度细节的同时响应自然语言指令进行忠实准确的图像编辑。

创新点

  • 采用简单的序列拼接方法（sequence concatenation approach）在单一统一架构中同时处理局部编辑和生成式上下文任务。
  • 引入 KontextBench 基准，包含 1026 个图像 - 提示词对，覆盖局部编辑、全局编辑、角色参考、风格参考和文本编辑五个任务类别。
  • 实现了显著更快的生成速度，支持交互式应用和快速原型设计工作流，同时保持与当前最先进系统的竞争力。
  • 在保持周围上下文完整的同时进行局部修改，并能在多轮迭代中有效提取视觉概念并在新环境中进行忠实再现。
  • 支持在图像内操纵文本（Typography），使更改能无缝融入周围内容。

文章精读

版本

  • FLUX.1 Kontext [max]：提供最高性能和高速度，在提示遵循度、排版生成和编辑一致性方面达到顶级水平且无速度妥协。
  • FLUX.1 Kontext [pro]：作为快速迭代图像编辑的先驱，提供 FLUX.1 质量的统一模型，支持精确的区域编辑或完整场景转换，以突破性的速度处理文本和图像输入。
  • FLUX.1 Kontext [dev]：是一个拥有 120 亿参数的开源权重模型，具备专有级别的图像编辑性能，可在消费级硬件上运行。

[2507.31XXX] FLUX · FLUX.1 Krea

一句话结论

FLUX.1 Krea [dev] 是 Black Forest Labs 与 Krea AI 联合开发的开源文生图模型，旨在通过独特的审美风格克服传统生成模型中常见的过度饱和纹理和'AI 感'问题，在保持与 FLUX.1 [dev] 架构生态兼容的同时，提供超越以往开源模型且媲美闭源 FLUX1.1 [pro] 的人机偏好表现。

解决的问题

现有的文生图生成模型普遍存在纹理过度饱和（oversaturated textures）的问题，导致生成的图像缺乏自然感和多样性，呈现出一种千篇一律的'AI 外观'（AI look），难以满足用户对真实感和视觉多样性的需求。

创新点

  • 提出'有观点的'（Opinionated）模型设计理念，主动引导生成具有独特审美且不过度饱和的图像。
  • 通过联合开发模式，为下游应用（如 Krea）提供高度灵活且可定制的基础模型，实现了基础模型与应用实验室的协同创新。
  • 在保持架构兼容性的前提下，显著提升了图像的真实感（photorealism）和视觉多样性，解决了开源模型在美学上的同质化痛点。

文章精读

版本

  • FLUX.1 Krea [dev]：作为与 Krea AI 联合开发的变体，专注于克服'AI 外观'问题，提供具有独特审美和卓越真实感的文生图能力，区别于标准 FLUX.1 [dev] 的通用生成特性。

[2511.25XXX] FLUX · FLUX.2

一句话结论

FLUX.2 是 Black Forest Labs 发布的下一代视觉智能模型，通过引入多参考控制、高精度文本渲染、空间推理增强及流匹配（flow matching）架构，实现了从 4B 到 32B 参数的多版本矩阵，旨在弥合生成内容与真实摄影在细节、物理逻辑和身份一致性上的差距。

解决的问题

现有模型在复杂场景下的身份一致性、多参考图像控制、真实物理逻辑（如光影、材质）以及复杂排版文本的生成能力上存在不足，难以满足生产级工作流对高精度和可控性的需求。

创新点

  • 支持同时参考多达 10 张图像的多参考控制（Multi-Reference Control），实现最佳的身份一致性和场景融合。
  • 显著提升图像细节与真实感，在织物纹理、建筑元素及物理光照方面大幅缩小与真实摄影的差距。
  • 实现可靠的复杂文本渲染，支持品牌色通过十六进制代码精确匹配及可读的 UI 排版和图形生成。
  • 增强空间推理能力，确保复杂场景中物体定位、物理效果和透视关系的准确性。
  • 引入流匹配（flow matching）架构，结合蒸馏技术，在保持前沿性能的同时优化推理速度。
  • 构建包含 4B、9B 及 32B 参数的多版本模型家族，覆盖从实时边缘部署到无延迟专业生成的全场景需求。

文章精读

版本

  • FLUX.2 [pro]：提供生产级的高质量图像生成与编辑，兼顾最高质量与最大速度，适用于专业工作流。
  • FLUX.2 [flex]：专注于极致精度，特别优化了文本可读性、小细节保留及完整的创意控制能力。
  • FLUX.2 [dev]：32B 参数版本，提供开放权重（Open Weights）和前沿性能，需高性能硬件支持，适合定制部署。

[2601.15XXX] FLUX · FLUX.2 [klein]

一句话结论

FLUX.2 [klein] 是 Black Forest Labs 发布的面向实时交互视觉智能的紧凑模型家族，通过统一的架构实现了文本生成、单参考及多参考图像编辑的端到端推理，在消费级硬件（如 13GB VRAM）上即可达到亚秒级生成速度，同时保持与大型模型相当的生成质量与多样性。

解决的问题

现有视觉生成模型在追求高质量的同时往往面临推理延迟高、显存占用大以及难以在消费级硬件上实时运行的问题，无法满足 AI 代理对实时视觉生成和快速迭代的需求，且缺乏在统一架构下高效处理多参考图像编辑的能力。

创新点

  • 实现了文本生成、图像编辑（单参考与多参考）的统一架构，无需切换模型即可端到端处理多种任务。
  • 通过极致的模型压缩与蒸馏技术，将推理步数压缩至 4 步，在消费级 GPU 上实现亚秒级（<0.5s）生成。
  • 在保持紧凑体积的同时，显著提升了多参考图像编辑（Multi-reference generation）的复杂构图与概念融合能力。
  • 提供了完整的量化方案（FP8 与 NVFP4），大幅降低显存占用并提升推理速度，适配更广泛的硬件环境。
  • Base 变体保留了完整的训练信号（Undistilled），为研究、微调（Fine-tuning）和 LoRA 训练提供了最大灵活性。

  • FLUX.2 [klein] 4B：完全开源（Apache 2.0），专为消费级 GPU 和边缘部署设计，在速度、可访问性和性价比上最优。
  • FLUX.2 [klein] 9B：旗舰小模型，在质量与延迟的帕累托前沿上表现最佳，支持多参考编辑，但需遵循 FLUX NCL 许可。
  • FLUX.2 [klein] Base：未蒸馏的基础模型，保留完整训练信号以支持微调和高输出多样性，牺牲了部分推理速度。

[2607.23XXX] FLUX · FLUX 3

一句话结论

FLUX 3 是 Black Forest Labs 发布的新一代多模态基础模型，基于 Self-Flow 架构统一学习图像、视频和音频，旨在构建感知、预测与行动于一体的视觉智能，目前已以 Early Access 形式提供视频生成能力，并计划逐步开放图像、动作预测及开源权重。

解决的问题

单一模态无法提供对现实世界的完整描述，图像仅捕捉特定时刻的空间结构，视频恢复时间维度但缺乏因果声学联系，音频揭示机械现象与声学间的因果关系，语言则连接感知与目标，因此需要统一架构来利用多模态间的相互约束（如声音匹配冲击、运动遵循质量守恒）以学习更准确的底层现实表征。

创新点

  • 提出 Self-Flow 方法，在统一架构内高效对齐多模态生成与理解，同时训练视频、图像和音频。
  • 实现原生多模态混合生成，支持从纯文本或输入参考（图像、视频）出发，联合生成包含音频的视频。
  • 具备强大的动作预测能力，既可直接集成于模型中，也可作为动力学感知基础供机器人微调。
  • 支持长达 20 秒的单次生成视频，包含多语言对话、音效及环境氛围，并支持关键帧控制与代理式长序列编排。
  • 引入 Draft 模式，以较低成本快速生成 HD 预览，确认方向后可增强为全分辨率 FHD 结果。
  • 在复杂提示处理、高精度文本渲染及多语言支持方面显著优于早期版本及竞品。
