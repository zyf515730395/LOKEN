[2411.02293] Hunyuan3D · Hunyuan3D 1.0

一句话结论

先生成六个一致视图，再一次性重建三维网格，把二维生成先验接到三维重建模型。

解决的问题

逐物体优化三维表示速度慢，多视图图像不一致又会破坏重建。

创新点

  • 把多视图生成和稀疏视图重建联合设计。
  • 零仰角相机布置与视图感知引导改善重建条件。

文章精读

版本

  • Hunyuan3D 1.0 Lite：较小多视图生成档，生成视图组成 960×640 网格，再重建三维。
  • Hunyuan3D 1.0 Standard：更大多视图生成档，使用 1536×1024 视图网格；两档都支持文字或图像条件。

训练数据

内部三维资产数据经过场景复杂度、纹理与变形筛选，归一化后渲染 24 个零仰角视图；训练和目标视图组合从中构造。

VAE 结构

/

Text Encoder

/

生成主体网络

Lite 的多视图扩散主干来自 SD 2.1，Standard 来自 SDXL，均使用参考注意力；第二阶段以 DINO 提取图像特征，再由 Transformer 融合已知与未知姿态图像并预测 triplane。

训练 Trick

  • 按视图调整 classifier-free guidance，协调几何稳定性与纹理细节。
  • 多视图扩散与重建分别训练；重建从 256 级输入训练后，以 512 级输入微调。

新提出的创新点

  • 把多视图生成和稀疏视图重建联合设计。

[2501.12202] Hunyuan3D · Hunyuan3D 2.0

一句话结论

从先画视图再重建，转向直接生成形状潜变量，并把纹理作为独立阶段。

解决的问题

几何与纹理需求不同，分开建模可以避免两者互相干扰并提高资产可编辑性。

创新点

  • 直接对紧凑三维形状表示建模，替代纯多视图重建路径。
  • 解耦几何和纹理，使网格可单独生成或重绘材质。

文章精读

版本

  • Hunyuan3D-DiT v2.0：直接在三维形状潜空间进行流式扩散，先生成无纹理网格。
  • Hunyuan3D-Paint v2.0：以形状和参考图为条件生成多视图纹理，再烘焙回网格。

训练数据

清洗后的三维资产提供表面点、法向、SDF 和多视图渲染监督；几何与纹理分别准备训练目标。

VAE 结构

ShapeVAE 以表面点坐标和法向编码为连续向量集合，解码器预测 SDF，再用 marching cubes 得到三角网格。

Text Encoder

/

生成主体网络

形状阶段为基于流匹配的 Hunyuan3D-DiT；Paint 阶段采用参考图与几何条件约束的多视图扩散。

训练 Trick

  • 重要性采样突出形状复杂区域，改善 ShapeVAE 细节重建。
  • 形状与纹理分阶段训练和推理。

新提出的创新点

  • 直接对紧凑三维形状表示建模，替代纯多视图重建路径。
  • 解耦几何和纹理，使网格可单独生成或重绘材质。

[2506.16504] Hunyuan3D · Hunyuan3D 2.5 · 技术报告

日期口径：arXiv 首次提交日，明确技术报告节点。

一句话结论

扩大形状基础模型，并让多通道 PBR 共享空间对应关系以减少材质错位。

解决的问题

复杂网格需要同时保持细节、光滑表面和锐利边缘，纹理也必须准确贴合几何。

创新点

  • 让 albedo 与金属度、粗糙度共享注意力位置关系，减少跨通道错位。
  • 形状模型规模扩展与材质空间对齐共同提高资产细节。

文章精读

版本

  • Hunyuan3D 2.5 LATTICE：形状基础模型扩展到报告中的最大 10B 规模，支持单图或四视图输入。
  • Hunyuan3D 2.5 PBR Paint：扩展多视图 PBR，增强通道间对齐及材质与几何的对应。

训练数据

扩大高质量复杂三维资产的数据、模型与计算规模；材质阶段使用多视图几何与 PBR 监督。

VAE 结构

/

Text Encoder

/

生成主体网络

LATTICE 为大规模形状扩散模型；纹理框架继承多视图 PBR 路线，使用 3D-aware RoPE 和双通道注意力。

训练 Trick

  • 形状模型使用 guidance 与 step distillation。
  • 材质通道共享参考注意力的空间权重，但保留各自的 value 表征。
  • 光照不变一致性损失和两阶段分辨率提升，改善材质解耦与几何对齐。

新提出的创新点

  • 让 albedo 与金属度、粗糙度共享注意力位置关系，减少跨通道错位。

[2608.02711] Hunyuan3D · Hunyuan3D-Buffalo 1.0 · 技术报告

日期口径：arXiv 首次提交日，明确技术报告节点。

一句话结论

让理解三维内容的视觉语言模型通过连接器指导形状扩散，连接生成、理解与编辑。

解决的问题

三维模型既要可生成，也需要能被语言理解和修改，分离的任务模型难以共享语义。

创新点

  • 把三维视觉语言理解结果用作扩散条件。
  • 统一三维任务数据及训练，允许语言驱动编辑。

文章精读

版本

  • Hunyuan3D-Buffalo 1.0：统一三维理解、文字到三维与编辑的多模态模型；此节点采用报告日，不宣称权重已开放。

训练数据

Nano3D v2 统一三维语料包含约 8700 万样本：2500 万理解、5000 万文字到三维、1200 万编辑对。

VAE 结构

形状生成分支沿用 Hunyuan3D 2.1 的三维潜表示路线。

Text Encoder

Hunyuan3D-VLM 建立多模态语义，三维结构与 RGB 外观经不同路径编码后与语言表征对齐。

生成主体网络

Hunyuan3D-VLM 与由 2.1 初始化的 3D-DiT 通过 MLP connector 连接；视觉语言语义作为三维生成条件。

训练 Trick

  • 先冻结视觉语言模型对齐连接器，再进行联合指令微调。
  • 结构和外观分别编码，统一训练三维理解、生成与编辑。

新提出的创新点

  • 把三维视觉语言理解结果用作扩散条件。
  • 统一三维任务数据及训练，允许语言驱动编辑。
