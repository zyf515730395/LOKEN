DeepSeek · DeepSeek LLM

文章精读

版本

DeepSeek LLM；发布节点 2023-11-29；变体：7B、67B。资料

训练数据

2T 中英文 token；网页语料经过过滤和去重。 官方资料.

VAE 结构

不适用：自回归语言生成不使用图像潜空间 VAE。 官方资料.

Text Encoder

不适用：文本由语言模型自身的词嵌入与解码器处理，无独立扩散条件文本编码器。 官方资料.

生成主体网络

自回归 Transformer decoder；7B 使用 MHA，67B 使用 GQA。 官方资料.

训练 Trick

AdamW、多阶段学习率衰减；预训练上下文 4096。 官方资料.

新提出的创新点

系统探索数据与模型规模扩展，并公开中间训练检查点。 官方资料.

局限性

公开模型上下文为 4096 token。 官方资料.

DeepSeek · DeepSeek-R1

文章精读

版本

DeepSeek-R1；发布节点 2025-01-20；变体：DeepSeek-R1、DeepSeek-R1-Zero、R1-Distill Qwen、R1-Distill Llama。资料

训练数据

R1 以 V3-Base 为起点；拒绝采样构建约 600K 推理和 200K 非推理样本。 官方资料.

VAE 结构

不适用：自回归语言生成不使用图像潜空间 VAE。 官方资料.

Text Encoder

不适用：文本由语言模型自身的词嵌入与解码器处理，无独立扩散条件文本编码器。 官方资料.

生成主体网络

R1/R1-Zero 基于 V3-Base；蒸馏版分别以 Qwen、Llama 为底座，不共享参数规模。 官方资料.

训练 Trick

R1-Zero 直接 RL；R1 加入冷启动数据、推理 RL、拒绝采样 SFT 与最终 RL；采用 GRPO。 官方资料.
