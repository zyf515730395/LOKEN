  • Z-Image：未经 Turbo 少步蒸馏的基础生成模型；官方建议 50 步、支持 CFG 与负向提示，便于多样化创作和微调。
  • Z-Image-Omni-Base · Announced：官方仓库列为待发布，面向生成与编辑的预训练基础模型；不把待发布说明当作权重已发布。
  • Z-Image-Edit · Announced：官方仓库列为待发布的编辑微调模型；实际发布日与新增技术细节：/。
训练数据

分阶段训练使用清洗的图文数据，配合 Z-Captioner、OCR 与知识增强描述；从低分辨率逐渐扩展到更完整的生成任务。
VAE 结构

采用 FLUX VAE 将图像编码为潜变量。
Text Encoder

Qwen3-4B 编码文本；编辑路线额外使用 SigLIP2 视觉语义条件。
生成主体网络

6B S3-DiT 将文本、视觉语义和 VAE 图像 token 串接为统一序列；采用统一三维 RoPE。
训练 Trick
  • Decoupled-DMD 分离 CFG augmentation 与 distribution matching；DMDR 联合 DMD 与 RL 后训练。
  • 分阶段预训练、SFT 和后训练逐步扩展质量与指令能力。
新提出的创新点
  • 单流设计共享模态间计算，以提高参数利用率。
  • 区分 CFG 增强和分布匹配的作用，再联合 DMD 与 RL 优化。
局限性
  • 技术报告指出紧凑模型的世界知识、意图理解和复杂推理有限，需要提示词增强补偿。
