生成主体网络

自回归 Transformer decoder；7B 使用 MHA，67B 使用 GQA。 官方资料.

236B 总参数、每 token 激活 21B；MLA 与 DeepSeekMoE。 官方资料.

融合 V2-Chat 与 Coder-V2-Instruct 的语言模型；模型细节指向 V2。 官方资料.

671B 总参数、37B 激活；MLA 与 DeepSeekMoE。 官方资料.

R1/R1-Zero 基于 V3-Base；蒸馏版分别以 Qwen、Llama 为底座，不共享参数规模。 官方资料.

671B 总参数、37B 激活、128K 上下文；单模型支持思考与非思考模式。 官方资料.

在 V3.1-Terminus 上引入 DeepSeek Sparse Attention（DSA）的 Transformer。 官方资料.

MoE：Pro 1.6T/激活49B，Flash 284B/激活13B；1M上下文；CSA+HCA 混合注意力。 官方资料.

训练 Trick

AdamW、多阶段学习率衰减；预训练上下文 4096。 官方资料.

预训练后进行监督微调与强化学习。 官方资料.

/

FP8 混合精度、SFT/RL、从 R1 系列蒸馏推理模式。 官方资料.

R1-Zero 直接 RL；R1 加入冷启动数据、推理 RL、拒绝采样 SFT 与最终 RL；采用 GRPO。 官方资料.

两阶段长上下文扩展；权重与激活采用 UE8M0 FP8 scale 格式。 官方资料.

为隔离稀疏注意力效果，训练配置与 V3.1-Terminus 对齐。 官方资料.

Muon；领域专家先分别 SFT/GRPO，再 on-policy 蒸馏整合。 官方资料.

/
新提出的创新点

系统探索数据与模型规模扩展，并公开中间训练检查点。 官方资料.

MLA 压缩 KV 缓存，细粒度 MoE 降低每 token 计算量。 官方资料.

把通用对话和代码能力整合进同一模型，改进写作与指令遵循。 官方资料.

无辅助损失负载均衡与多 token 预测（MTP）。 官方资料.

展示纯 RL 诱发自验证和长思维链，并把推理能力蒸馏至较小模型。 官方资料.

混合思考模式与工具/Agent 后训练优化。 官方资料.

细粒度稀疏注意力提升长上下文训练与推理效率。 官方资料.

压缩注意力与 mHC 超连接，提高长上下文效率和跨层稳定性。 官方资料.

新架构系列的最小模型，原生支持视觉理解；具体网络、参数量及训练配方未披露。 官方资料.
局限性

公开模型上下文为 4096 token。 官方资料.

官方提示通用 Hugging Face 实现速度低于内部实现。 官方资料.

官方 BF16 本地部署示例要求 8×80GB GPU。 官方资料.

/

R1-Zero 有可读性和语言混杂问题；R1 仍有语言混杂及提示敏感性限制。 官方论文。

/

实验版本，目标是维持原模型质量并验证效率；官方基准并非所有任务均提升。 官方资料.

官方指出 Flash 在纯知识及最复杂 Agent 任务上弱于 Pro。 官方资料.
