训练数据

包含自然图像、人物、设计和合成数据的大规模图文语料；通过分类清洗、重标注与逐步增加文本复杂度的课程训练，覆盖视觉与文字两类能力。

/

使用原生多图层设计文件建立分层数据，并构造 RGB、RGBA 与多图层条件任务；训练覆盖最多 20 层的分解。

按任务构造图文描述与编辑数据，结合高分辨率数据和合成样本；通过错误归因与反馈补充能力缺口。

/
VAE 结构

图像 VAE 在空间维度压缩 8 倍，潜变量为 16 通道。

/

RGBA-VAE 共用 RGB/RGBA 潜空间；输入和输出卷积由 3 通道扩到 4 通道，显式保存 alpha，图层维度不做压缩。

空间压缩由上一代 8 倍提高到 16 倍，减少高分辨率输出的潜变量数量。

/
Text Encoder

Qwen2.5-VL-7B 提供文本与视觉语义条件；编辑任务还使用 VAE 图像编码保留外观。

输入图像分别进入 Qwen2.5-VL 和 VAE，提供语义与外观条件。

沿用 Qwen 系列视觉语言条件编码；输入图像提供分层所需语义。

冻结的 Qwen3-VL 作为多模态条件编码器。

/
生成主体网络

20B MMDiT：图像与文本各有参数，在联合注意力中交互；60 层主干使用多模态位置编码 MSRoPE。

基于 Qwen-Image 的 MMDiT 图像编辑模型。

VLD-MMDiT 在可变数量的图层潜变量上联合去噪，Layer3D RoPE 显式表示图层位置。

MMDiT 主干使用 MSRoPE、QK RMSNorm、LayerNorm 和 SwiGLU；在统一框架中处理生成与编辑。

/
训练 Trick
  • 逐步提高分辨率与文字难度；把 T2I、I2I、TI2I 任务纳入训练。
  • 高质量监督微调与强化学习用于改善审美和指令遵循。
  • /
  • 按文本到 RGB、文本到 RGBA、文本到多层 RGBA、图像到多层 RGBA 逐步训练。
  • 使用流匹配训练分层生成过程。
  • 多阶段、多分辨率训练逐步扩展生成与编辑能力。
  • 自动错误归因连接评估和数据改进，形成数据反馈循环。
  • /
新提出的创新点
  • 将语义理解与视觉重建两条条件路径结合，兼顾编辑含义和输入外观。
  • 通过文字专门数据与课程学习加强中英文精确绘制。
  • 语义条件与外观条件并行注入，使语义级和外观级编辑共享模型。
  • 共享 RGB/RGBA 表征，避免把透明度视为后处理结果。
  • 可变图层数量的扩散建模允许一次生成结构化图层。
  • 提高潜空间压缩率，以控制原生 2K 的计算量。
  • 生成与编辑统一建模，数据改进围绕具体失败类型展开。
  • 公开能力变化（实现未披露）：支持更长的图文指令和复杂版面；官方披露的能力变化不等于公开了训练架构。
