查看代际精读
版本
FLUX.1精读
  • FLUX.1 [pro]：提供最佳性能图像生成，通过 API 访问，支持企业定制解决方案
  • FLUX.1 [dev]：开放权重的指导蒸馏模型，适用于非商业应用，比同尺寸标准模型更高效
  • FLUX.1 [schnell]：专为本地开发和个人使用设计的最快模型，采用 Apache2.0 许可
FLUX1.1 [pro]精读
  • FLUX1.1 [pro]：相比 FLUX.1 [pro]，在保持相同输出质量的前提下实现六倍生成速度提升，并在基准测试中取得更高 Elo 分数。
FLUX1.1 [pro] Ultra精读
  • FLUX1.1 [pro] Ultra：相比标准 FLUX1.1 [pro]，分辨率提升至 4MP，并新增 Raw Mode 模式以增强自然摄影的真实感。
FLUX.1 Tools精读
  • FLUX.1 Fill：专注于图像局部重绘和扩展，支持基于文本和掩码的编辑，且未受废弃影响。
  • FLUX.1 Depth：提供基于深度图的结构引导以维持构图，但已被官方宣布废弃并停止维护。
  • FLUX.1 Canny：提供基于 Canny 边缘的结构引导以维持构图，但已被官方宣布废弃并停止维护。
  • FLUX.1 Redux：作为适配器实现图像变体和重风格化，支持结合图像与文本提示生成，未受废弃影响。
FLUX.1 Kontext精读
  • FLUX.1 Kontext [max]：提供最高性能和高速度，在提示遵循度、排版生成和编辑一致性方面达到顶级水平且无速度妥协。
  • FLUX.1 Kontext [pro]：作为快速迭代图像编辑的先驱，提供 FLUX.1 质量的统一模型，支持精确的区域编辑或完整场景转换，以突破性的速度处理文本和图像输入。
  • FLUX.1 Kontext [dev]：是一个拥有 120 亿参数的开源权重模型，具备专有级别的图像编辑性能，可在消费级硬件上运行。
FLUX.1 Krea精读
  • FLUX.1 Krea [dev]：作为与 Krea AI 联合开发的变体，专注于克服'AI 外观'问题，提供具有独特审美和卓越真实感的文生图能力，区别于标准 FLUX.1 [dev] 的通用生成特性。
FLUX.2精读
  • FLUX.2 [pro]：提供生产级的高质量图像生成与编辑，兼顾最高质量与最大速度，适用于专业工作流。
  • FLUX.2 [flex]：专注于极致精度，特别优化了文本可读性、小细节保留及完整的创意控制能力。
  • FLUX.2 [dev]：32B 参数版本，提供开放权重（Open Weights）和前沿性能，需高性能硬件支持，适合定制部署。
FLUX.2 [max]精读
  • FLUX.2 [max]：定位最高性能，具备最强的编辑一致性、提示遵循能力、风格表现力以及实时网络信息整合（接地式生成）能力。
FLUX.2 [klein]精读
  • FLUX.2 [klein] 4B：完全开源（Apache 2.0），专为消费级 GPU 和边缘部署设计，在速度、可访问性和性价比上最优。
  • FLUX.2 [klein] 9B：旗舰小模型，在质量与延迟的帕累托前沿上表现最佳，支持多参考编辑，但需遵循 FLUX NCL 许可。
  • FLUX.2 [klein] Base：未蒸馏的基础模型，保留完整训练信号以支持微调和高输出多样性，牺牲了部分推理速度。
FLUX 3精读
  • FLUX 3 Video · Early Access：当前唯一可用版本，提供视频与音频联合生成、多模态输入参考及代理式长序列编排能力，处于早期访问阶段。
  • FLUX 3 Image · Announced：专注于图像合成与编辑，支持多种风格、宽高比及高分辨率，预计在未来几周内开放早期访问。
  • FLUX 3 Action · Announced：通过选定合作伙伴（如 mimic robotics）提供动作预测功能，利用预训练视频骨干进行动力学感知的机器人控制，尚未公开独立访问。
  • FLUX 3 Dev · Announced：提供多模态骨干网络的开源权重访问，供内容创作和动作预测研究使用，即将发布。

新提出的创新点
  • Flow Matching 作为包含扩散模型的通用方法
  • 混合多模态与并行扩散 Transformer 块架构
  • 指导蒸馏模型实现效率与质量平衡
  • 微调以保留预训练的全部输出多样性
  • 将图像生成和编辑统一在单一架构中，无需微调即可通过简单指令进行修改。
  • 通过流匹配（flow matching）方法在潜在空间（latent space）中实现上下文感知的图像生成和编辑。
  • 在多轮迭代中显著改善了对象和角色的保留能力，解决了现有模型的一致性退化问题。
  • 引入'有观点的'（Opinionated）概念，使模型在生成过程中主动偏好特定的美学风格以对抗过度饱和。
  • 通过基础模型与应用方（Krea AI）的深度协作，验证了针对下游微调（down-stream finetuning）的专用基础模型开发路径的有效性。
  • 将多参考图像控制（Multi-Reference Control）作为核心功能直接集成并大规模应用。
  • 通过流匹配（flow matching）替代传统扩散过程，提升生成效率与质量平衡。
  • 构建从 4B 到 32B 的完整模型家族，针对不同硬件和延迟需求提供差异化方案。
  • 引入基于 JSON 的控制系统和提示词上采样（prompt upsampling）技术以增强推理灵活性。
  • 显著增强世界知识（World Knowledge）基础，使模型更 grounded 于现实世界的逻辑、光照和空间关系。
  • 将多参考图像编辑能力集成到紧凑模型中，打破了以往仅大模型具备此能力的限制。
  • 提出“交互式视觉智能”愿景，强调模型在实时循环迭代中的能力而非单次生成质量。
  • 通过 KV 缓存技术（9B KV 变体）在保持质量的同时进一步压缩推理延迟。
  • 提供 FP8 和 NVFP4 量化版本，将推理速度提升 1.6 至 2.7 倍，显存占用降低 40% 至 55%。
  • 将感知、模拟和执行统一在同一模型中以支持物理 AI 和内容创作。
  • 利用多模态间的相互约束（如声音匹配冲击、运动遵循质量）来增强对底层现实的理解。
  • 通过 Draft 模式实现低成本快速迭代与高质量最终渲染的分离。
  • 支持跨模态的代理式编排（Agentic chaining），将独立片段连接为多镜头长序列。
  • 原生支持视频与音频的联合生成，确保声音与物理事件及多语言对话的同步。
局限性
  • FLUX.1 [dev] 与 FLUX.1 [schnell] 的官方模型卡明确指出，模型不适合提供事实信息，并可能放大训练数据中的社会偏见。
  • 两份官方模型卡都记录了 prompt-following 失败：输出可能不符合 prompt，且结果明显受 prompting style 影响。
  • 连续多轮编辑会累积视觉伪影并降低图像质量；官方示例在六轮编辑后出现明显退化。
  • 模型偶尔会忽略 prompt 中的特定要求，不能保证每次准确遵循编辑指令。
  • 世界知识仍然有限，可能生成与上下文事实不符的内容。
  • distillation 过程可能引入影响输出保真度的视觉伪影。
  • “Opinionated”训练目标会主动偏向独特且特定的审美，官方也承认模型存在 idiosyncrasies，因此它并不以风格中性为目标。
  • 官方只报告了总体 human-preference 对比，没有给出 prompt-following、文字渲染、组合关系或跨域失败案例的分项结果，实验不足以说明这些维度的泛化。
  • 未量化的 32B FLUX.2 [dev] 推理脚本需要 H100 级显存；消费级 RTX 4090/5090 部署示例依赖 4-bit 量化与远程 text encoder，显示其完整精度本地推理的显存门槛很高。
  • FLUX.2 [dev] 官方仓库明确称其显著受益于 prompt upsampling；本地 upsampling 示例还要运行 Mistral-Small-3.2-24B-Instruct-2506，进一步增加计算与内存负担。
  • 多参考输入存在明确规模边界：官方建议 FLUX.2 [dev] 最多使用 6 张参考图，超过该范围未被推荐或验证。
  • Distilled 变体以 4-step 推理换取实时速度；Base 变体保留完整训练信号但需要约 50 steps，推理成本明显更高。
  • 该系列为速度而非最高细节优化，且不提供 prompt upsampling；输出质量更依赖用户自行写出充分描述的 prompt。
  • 多参考编辑最多支持 4 张参考图，不能覆盖 FLUX.2 大型号支持的 8 至 10 张参考输入。
  • 4B 版本在消费级 GPU 上运行仍约需 13GB VRAM，低显存设备需要额外量化或卸载方案。
  • 单次原生视频生成最长为 20 秒；更长序列需要把多个片段串联，超出单次生成的时序建模范围。
  • 原生输出为 HD（720p），Full HD（1080p）通过 upscaling 获得，因此 FHD 不是模型直接生成的原生分辨率。
  • Self-Flow 的公开量化证据只包含各模态归一化 generation error，以及四组 manipulation task 的微调成功率；尚未覆盖长时序一致性、广泛物理场景和跨域动作泛化。
